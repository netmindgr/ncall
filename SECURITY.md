# Αναφορά προβλήματος ασφάλειας

Το nCall βρίσκεται σε ενεργή ανάπτυξη· οι διορθώσεις ασφάλειας κυκλοφορούν ως νέα έκδοση και εγκαθίστανται με τις αυτόματες ενημερώσεις.

Για πιθανό πρόβλημα ασφάλειας στην εφαρμογή χρησιμοποιήστε την ιδιωτική αναφορά του GitHub ([Report a vulnerability](https://github.com/netmindgr/ncall/security/advisories/new)) ή επικοινωνήστε με info@netmind.gr. Αποφύγετε την ανάρτηση κωδικών, προσωπικών δεδομένων ή μη δημοσιευμένων λεπτομερειών εκμετάλλευσης σε issues.

Οι βιβλιοθήκες τρίτων και οι ακριβείς εκδόσεις τους καταγράφονται στο dependency-versions.txt.

## English

Please report security issues privately through [GitHub private vulnerability reporting](https://github.com/netmindgr/ncall/security/advisories/new) or by email to info@netmind.gr. Do not open public issues for security problems. Fixes are released as new versions and installed by the automatic updater.
